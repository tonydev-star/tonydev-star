## 🛠️ Currently Building

**[distributed-kv](https://github.com/tonydev-star/distributed-kv)** — A distributed key-value store built from scratch in Python, culminating in a hand-rolled **Raft consensus** implementation (the same algorithm behind etcd/Kubernetes and CockroachDB).

- ✅ Write-ahead log with `fsync`-backed durability and full crash recovery
- ✅ Async TCP server/client with a live browser dashboard
- 🚧 Raft consensus: leader election, log replication, network-partition testing *(in progress)*
- 🔜 Multi-node cluster deployment, chaos testing, Prometheus/Grafana observability

> Built to deeply understand the internals of the systems powering production databases — not to wrap an existing one.
